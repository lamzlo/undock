# Undock

Undock извлекает текст из документов и разбивает его на фрагменты для дальнейшей обработки. Результат сохраняется в JSON или выводится в терминал.

Поддерживаются TXT, Markdown, HTML, DOCX и PDF с текстовым слоем. Сканированные PDF и картинки требуют OCR — его в этой версии нет. Таблицы и сложная вёрстка преобразуются в обычный текст; порядок и форматирование могут измениться.

## Установка

Нужен Python 3.10 или новее:

```bash
pip install -r requirements.txt
```

Зависимость нужна для PDF. Остальные форматы работают средствами Python.

## Использование

```bash
python undock.py документ.pdf -o результат.json
python undock.py заметки.md --size 1000 --overlap 100
```

`--size` задаёт максимальный размер фрагмента в символах, `--overlap` — число общих символов соседних фрагментов. По умолчанию это 1500 и 150. Без `-o` результат выводится в терминал.

## Проверка
